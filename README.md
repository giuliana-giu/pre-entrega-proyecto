## Descripción del proyecto de TalentoTech Front End - JS:

Este proyecto es una página E-commerce desarrollada como parte de del curso. 
La página está estructurada con HTML semántico y utiliza las etiquetas<header>, <main>, y <footer> 
para organizar el contenido. El objetivo es aprender a crear la estructura básica de una página web 
y prepararla para futuras mejoras con CSS y JavaScript.

## Configuración de Formspree (Día 3)

1. Creación de una cuenta en [Formspree.io].
2. Generación de un nuevo formulario para obtener la URL del endpoint (`https://formspree.io/f/mppzjele`).
3. Vinculación del endpoint al formulario HTML mediante el atributo `action="https://formspree.io/f/mppzjele"` y el método `method="POST"`.
4. Asignación del atributo `name` a cada campo (`nombre`, `email`, `mensaje`) para que los datos sean identificados y enviados correctamente.

### ¿Por qué es útil Formspree?
Ya que permite procesar y enviar las respuestas de un formulario de contacto HTML directamente a un correo electrónico sin necesidad de programar un servidor propio  ni utilizar scripts en el servidor.
